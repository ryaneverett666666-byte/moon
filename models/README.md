# Папка моделей зданий

Сюда кладите свои 3D-модели построек (формат **GLB**). Игра автоматически
загрузит их и расставит на поверхности Луны вместо встроенных low-poly заготовок.

## Имена файлов

Файл должен называться так же, как тип здания (в точности, как в коде):

| Файл               | Здание                     |
|--------------------|----------------------------|
| `dome.glb`         | Купол (жильё)              |
| `power.glb`        | Реактор (энергия)          |
| `mine.glb`         | Шахта                      |
| `beacon.glb`       | Маяк связи                 |
| `outpost.glb`      | Аванпост                   |
| `lab.glb`          | Лаборатория                |
| `turret.glb`       | Турель                     |
| `logi.glb`         | Логистический центр        |
| `recon.glb`        | Разведывательный центр     |

## Требования к модели

1. Формат **GLB** (лучше бинарный), желательно один корневой узел-сцена.
2. Модель стоит ориентировать **осью Y вверх**, основание — у уровня Y = 0.
3. Размер не важен: игра сама масштабирует модель под нужную высоту здания
   (от радиуса сектора) и центрирует её по основанию.
4. Нужен `GLTFLoader` — он уже лежит в `vendor/GLTFLoader.js`
   (совместим с three r160).

## Как это работает

- При запуске игра делает `import('./vendor/GLTFLoader.js')` и пытается
  загрузить `./models/<тип>.glb` для каждого типа здания.
- Если файл есть — модель используется (с нормализацией высоты).
- Если файла нет — используется встроенная простая геометрия.
- После загрузки модели маркеры перестраиваются автоматически.

Просто положите `.glb` файлы в эту папку и обновите страницу.
