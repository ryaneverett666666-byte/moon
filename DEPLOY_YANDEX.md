# Публикация «Луна 2087» в Яндекс Играх

## 1. Что уже готово в коде

- **Yandex Games SDK** загружается с `https://yandex.ru/games/sdk/v1` автоматически (если есть интернет).
- **GameplayAPI**: `start()` вызывается при старте игры, `stop()` — при сворачивании/закрытии (аналитика платформы).
- **Реклама**:
  - вознаграждаемая (rewarded) — 12 строителей, бесплатная смена режима, очки разрушения;
  - полноэкранная (interstitial) — автоматически раз в 5 минут активной игры (первая — через 4 минуты после инициализации SDK);
  - в офлайн-режиме реклама просто не показывается (игра не ломается).
- **Облачные сохранения**: сохранение в профиль игрока (`player.setData`) + авто-загрузка.
- **Офлайн/PWA**: service worker, всё локальное (three.js, текстуры, музыка, GLTFLoader) — внешних ресурсов, кроме SDK, нет.
- **Сохранение при сворачивании** — `visibilitychange` + `beforeunload`.

## 2. Требования платформы (проверено)

- Все пути относительные: `index.html`, `manifest.json`, `service-worker.js`, `icons/`, `models/`, `textures/`, `vendor/`, `OutThere.mp3`.
- Игра работает в портретной ориентации (в манифесте `orientation: portrait`), корректно отображается и на десктопе.
- Размер архива ~… МБ (лимит платформы 200 МБ — ок).

## 3. Шаги публикации

1. **Упакуйте игру в ZIP** (архив `moon2087_yandex.zip` уже создан скриптом; при необходимости пересоберите):
   ```
   Compress-Archive -Path index.html,manifest.json,service-worker.js,icons,models,textures,vendor,OutThere.mp3 -DestinationPath moon2087_yandex.zip -Force
   ```
   Внутри архива `index.html` должен лежать в корне (без папок-обёрток).

2. Зайдите в [Кабинет разработчика Яндекс Игр](https://games.yandex.ru/console/) → «Добавить игру» → загрузите ZIP.

3. Заполните карточку:
   - **Название**: Луна 2087
   - **Короткое описание**: колонизация Луны, строительство, стратегия
   - **Иконка 512×512**: `icons/icon-512.png`
   - **Обложка/скриншоты**: сделайте скриншоты игры (можно перерисовать в кабинете)
   - **Категория**: Стратегии / Симуляторы
   - **Ориентация**: портретная
   - **Возраст**: 12+

4. В разделе «Настройки» укажите **URL загрузки HTML**: `/index.html`.

5. Протестируйте в песочнице: нажмите «Тестировать» — убедитесь, что LoadingAPI завершился (экран загрузки пропал), игра стартовала, сохранения работают.

## 4. Чек-лист перед модерацией

- [ ] Игра запускается из ZIP без ошибок консоли
- [ ] Ресурсы не грузятся с внешних доменов (кроме yandex SDK)
- [ ] Сохранение переживает перезагрузку
- [ ] Работает реклама: rewarded за строителей и режимы, interstitial раз в 5 минут
- [ ] Игра не блокируется без интернета (SW-кеш)
- [ ] Нет обидного контента в названии колонии (есть фильтр мата)

## 5. Советы

- В настройках кабинета включите «Показывать кнопку сабскрайба/лайка», если хотите.
- Обновления: меняйте `CACHE_VERSION` в `service-worker.js` (сейчас `moon2087-v3`) и пересобирайте ZIP.
- Скриншоты лучше делать в реальном браузере с включённым WebGL.
