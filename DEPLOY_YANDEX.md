# Публикация «Луна 2087» в Яндекс Играх

## 1. Что уже готово в коде

- **Yandex Games SDK** подключён статическим тегом в `<head>` по требованиям платформы:
  ```html
  <!-- Yandex Games SDK -->
  <script async src="/sdk.js" onload="initSDK()"></script>
  ```
  Скрипт загружается асинхронно (`async`, не блокирует рендеринг), а инициализация — `YaGames.init()`, `LoadingAPI.ready()`, `getPlayer()` — выполняется в глобальной функции `initSDK()`, которая вызывается из `onload` сразу после загрузки `/sdk.js` (порядок: `/sdk.js` → `YaGames.init()`, как требует документация). Если `/sdk.js` недоступен (офлайн, локальная разработка), игра работает без SDK без ошибок.
- **GameplayAPI** (аналитика платформы):
  - `start()` — старт новой игры, закрытие меню/модалок, снятие с паузы, возврат во вкладку браузера, возобновление после показа рекламы;
  - `stop()` — открытие меню (панель вкладок, настройки, модалки атаки/справки, туториал), пауза при сворачивании вкладки, показ полноэкранной или rewarded-рекламы, окончание игры (победа/поражение);
  - вызовы сбалансированы флагом `_gp`: повторные `start()`/`stop()` без смены состояния на платформу не отправляются; `start()` не отправляется после окончания игры и пока открыта модалка.
- **Реклама**:
  - вознаграждаемая (rewarded) — 12 строителей, юниты, лояльность, очки разрушения, бесплатная смена режима (только по действию игрока). **Выдача двухэтапная**: после `onRewarded` (ролик досмотрен) по центру экрана открывается модальное окно **«Забрать награду»** (как обучающие подсказки); ресурсы начисляются ТОЛЬКО по нажатию его кнопки. Автоначисления нет — даже если колбэк `onRewarded` придёт без реального показа, без нажатия кнопки ресурсы не выдаются;
  - полноэкранная (interstitial) — только при начале НОВОЙ игры (после первого прохождения): вызывается `showFullscreenAd`, а показывать ли рекламу — решает сама платформа; автопоказа и таймеров нет;
  - первый запуск игры — без рекламы (пока не поставлено имя колонии, флаг `luna_played` не установлен);
  - в офлайн-режиме реклама просто не показывается (игра не ломается).
- **Облачные сохранения**: сохранение в профиль игрока (`player.setData`) + авто-загрузка.
- **Офлайн/PWA**: service worker, всё локальное (three.js r160 + OrbitControls в одном `engine.module.js`, текстуры, музыка) — внешних ресурсов, кроме SDK, нет.
- **Сохранение при сворачивании** — `visibilitychange` + `beforeunload`.

## 2. Требования платформы (проверено)

- **Все файлы лежат в корне архива, подпапок нет** (платформа отдаёт только файлы корня — файлы из подпапок возвращают 404): `index.html`, `engine.module.js`, `manifest.json`, `service-worker.js`, `OutThere.mp3`, `earth_color.jpg`, `milky_way.jpg`, `moon_color.jpg`, `icon-48.png`…`icon-512.png`.
- Игра работает в портретной ориентации (в манифесте `orientation: portrait`), корректно отображается и на десктопе.
- Размер архива ~… МБ (лимит платформы 200 МБ — ок).

## 3. Шаги публикации

1. **Упакуйте игру в ZIP** (архив `moon2087_yandex.zip` уже создан скриптом; при необходимости пересоберите):
   ```
   Compress-Archive -Path index.html,engine.module.js,manifest.json,service-worker.js,OutThere.mp3,earth_color.jpg,milky_way.jpg,moon_color.jpg,icon-48.png,icon-72.png,icon-96.png,icon-128.png,icon-144.png,icon-192.png,icon-512.png -DestinationPath moon2087_yandex.zip -Force
   ```
   Внутри архива ВСЕ файлы должны лежать в корне — без единой подпапки (платформа не отдаёт файлы из подпапок, они дают 404).

2. Зайдите в [Кабинет разработчика Яндекс Игр](https://games.yandex.ru/console/) → «Добавить игру» → загрузите ZIP.

3. Заполните карточку:
   - **Название**: Луна 2087
   - **Короткое описание**: колонизация Луны, строительство, стратегия
   - **Иконка 512×512**: `icon-512.png` (в корне архива)
   - **Обложка/скриншоты**: сделайте скриншоты игры (можно перерисовать в кабинете)
   - **Категория**: Стратегии / Симуляторы
   - **Ориентация**: портретная
   - **Возраст**: 12+

4. В разделе «Настройки» укажите **URL загрузки HTML**: `/index.html`.

5. Протестируйте в песочнице: нажмите «Тестировать» — убедитесь, что LoadingAPI завершился (экран загрузки пропал), игра стартовала, сохранения работают.

## 4. Чек-лист перед модерацией

- [ ] В `<head>` есть `<script async src="/sdk.js" onload="initSDK()">` (SDK подключён до `YaGames.init()`)
- [ ] `GameplayAPI.start()`/`stop()` вызываются при старте/паузе игры, открытии меню, показе рекламы и окончании игры
- [ ] Игра запускается из ZIP без ошибок консоли
- [ ] Внутри ZIP есть `engine.module.js` в корне (проверка: `tar -tf moon2087_yandex.zip | findstr /C:"engine.module.js"`)
- [ ] В ZIP нет ни одной подпапки (`tar -tf moon2087_yandex.zip` — только имена файлов, без `/` в путях)
- [ ] Ресурсы не грузятся с внешних доменов (кроме yandex SDK)
- [ ] Сохранение переживает перезагрузку
- [ ] Работает реклама: rewarded — награда только через кнопку «Забрать награду» (появляется по `onRewarded`, без автоначисления); interstitial — только при старте новой игры (решение о показе — у платформы)
- [ ] Игра не блокируется без интернета (SW-кеш)
- [ ] Нет обидного контента в названии колонии (есть фильтр мата)

## 5. Советы

- В настройках кабинета включите «Показывать кнопку сабскрайба/лайка», если хотите.
- Обновления: меняйте `CACHE_VERSION` в `service-worker.js` (сейчас `moon2087-v3`) и пересобирайте ZIP.
- Скриншоты лучше делать в реальном браузере с включённым WebGL.

## 7. Устранение неполадок

### 7.1. Ошибки 404 на файлы игры (`vendor/*`, `textures/*`)

**Симптом:** игра застревает на загрузке либо стартует без текстур. В консоли
отладочной панели — 404 на файлы, лежащие в ПОДПАПКАХ:

```
app-<id>.games.s3.yandex.net/<id>/<hash>/vendor/three.module.js           404
app-<id>.games.s3.yandex.net/<id>/<hash>/textures/earth_color.jpg         404
app-<id>.games.s3.yandex.net/<id>/<hash>/textures/milky_way.jpg           404
app-<id>.games.s3.yandex.net/<id>/<hash>/textures/moon_color.jpg          404
```

**Причина:** платформа Яндекс Игр отдаёт только файлы в КОРНЕ загруженного ZIP.
Любые файлы внутри подпапок возвращают 404 (это подтверждено: `index.html`,
`engine.module.js`, `OutThere.mp3` в корне грузятся, а `vendor/*` и `textures/*`
в подпапках — нет). Дополнительно панель может тестировать устаревший билд —
признак: неизменный `APP_VERSION` в консоли SDK.

**Текущее состояние (исправлено):**
- three.js r160 + OrbitControls объединены в один модуль [`engine.module.js`](engine.module.js) в корне (import map удалена, `vendor/` в рантайме не используется);
- текстуры и иконки перенесены в корень (`earth_color.jpg`, `milky_way.jpg`, `moon_color.jpg`, `icon-*.png`);
- весь ZIP состоит только из файлов в корне, подпапок нет;
- service worker кеширует только корневые файлы.

**Проверка и загрузка:**
1. Убедиться, что в архиве нет подпапок:
   ```
   tar -tf moon2087_yandex.zip
   ```
   Вывод — только имена файлов без `/` в путях.
2. Загрузить новый ZIP в кабинет разработчика → «Тестировать».
3. **Важно.** Отладочная панель держит старый билд до перезагрузки страницы:
   если в консоли SDK по-прежнему старый `APP_VERSION` или видны старые ошибки —
   закройте вкладку панели и откройте её заново (или Ctrl+Shift+R / другая сессия браузера).

### 7.2. Реклама «по времени» в отладочной панели

В коде игры НЕТ автоматического показа полноэкранной рекламы: таймеры
(`_adNext`/`__adNext`) и вызов из игрового цикла удалены; `tryShowInterstitial()`
вызывается только при старте НОВОЙ игры после первого запуска.
Если interstitial появляется «сам по себе» в песочнице — это тестовая реклама
самой платформы (в логах видно `AdvAdvManager force show fullscreen adv`),
из кода игры она не управляется. В боевой версии показ интерстишалов
регулируется политикой платформы в кабинете разработчика, а не кодом игры.
